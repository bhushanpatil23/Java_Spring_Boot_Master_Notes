Deploy on Elastic Beanstalk woth Load balancer, EC2, Autoscaling and RDS connection

Elastic Beanstalk is an orchestration service. It uses the load balancers and and EC2 instances and autoscaling groups behind the scene to deploy and to manage our applications. We can deploy all sorts of application using Elastic Beanstalk. There is no additional charge for Elastic Beanstalk. Because it's just an simple orchestration service. It's not actual service basically it's used to facilitate orchestration between multiple other services like auto-scaling groups, load balancers and s3s and EC2 instances and all that.

Rolling update and deployment: i.e. how do you want to deploy on all EC2 instances(just like rolling restart in tcs BaNCS TA project as I heared there this is it)
	As we have set max four instances here :
	This is used when some new code is pushed there or any deployment is there :
	We can set the deployment policy like All at once, Rolling, Rolling with additional batch
	
	All at once: has some pros and cons:
	i.e. if we want to push new code at all instances at once that is all at once instances , SO the pros is that the all the code deployment is faster but the cons is that our application gets unavalble for some time.
	Other Option is Rolling:
	
	Rolling: The code gets deployed one at a time. so when the code gets deployed successfully at first instance then only at second instance and so on. So, in rolling is downtime is less and availability is high.
	
choose : Rolling -> fixed 
		deployment batch size: 1 instance at a time
